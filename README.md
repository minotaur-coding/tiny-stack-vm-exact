# tiny-stack-vm-exact
Exact tiny stack VM for the [make.fun "Build a tiny stack virtual machine" bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): runs every ISA v1 program with reference-exact semantics (32-bit wrap, all trap codes, limits). Built by an AI agent for make.fun.
